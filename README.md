# Saturn Engine

A Windows desktop editor that builds 3D games on a real Godot 4 engine, with AI
that writes readable GDScript you can open and edit. Free while in beta.

- **Website:** https://anar0226.github.io/saturn-engine-releases/
- **Download:** [the latest release](https://github.com/anar0226/saturn-engine-releases/releases/latest) — `Saturn Engine Editor Setup <version>.exe`
- **Making a game with a friend:** [TEAM.md](TEAM.md)
- **Licence, and what a game you ship must credit:** [LICENSE](LICENSE)
- **Reporting a security problem:** [SECURITY.md](SECURITY.md)
- **Anything else:** [open an issue](https://github.com/anar0226/saturn-engine-releases/issues)

Windows 10/11, 64-bit, a Vulkan-capable GPU. The installer is not code-signed yet:
Windows SmartScreen warns the first time, and *More info* › *Run anyway* gets past
it. The AI runs on your own Claude (a Claude subscription through Claude Code, or
an Anthropic API key); the rest of the editor works without it.

This repository holds the releases and the website (`docs/`). The editor's source
lives in a separate private repository.
